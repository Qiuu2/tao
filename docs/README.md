## 编号是什么意思

文档里到处出现的那几种编号：

| 前缀 | 含义 | 出处 |
|---|---|---|
| `D-xx` | 旧系统 ok112 的**缺陷** | 旧接口与源码缺陷清单 |
| `BR-xx` | **业务规则**（必须保留的行为） | 各模块设计稿 |
| `C-xx` | 与后台 C 服务 / 旧库之间的**契约**（不可更改） | 同上 |
| `F-xx` | 功能编号 | 新版Web重构开发手册 |
| `G-xx` | 幽灵表 / 幽灵字段（代码引用了但库里没有） | 同上 |
| `N-xx` | 实现时踩到并记下的坑 | 代码注释里 |
| `R1`…`R5` | 红线 | 开发文档第 2 章 |
