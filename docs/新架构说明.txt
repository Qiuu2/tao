### 2.2 技术栈建议

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | Vue 3 + Vite | 轻量、响应式、适合嵌入式Web服务 |
| UI组件库 | Element Plus | 成熟的后台管理UI组件 |
| 图表库 | ECharts | 终端状态统计、数据可视化 |
| 地图引擎 | Leaflet/MapLibre | 离线地图、终端拓扑定位 |
| 后端语言 | Go (Gin) 或 C++ (libevent) | 高并发、低资源占用 |
| 数据库 | MySQL | 无需额外服务，用现有的audioserver.sql|
| 音频处理 | FFmpeg + 自研编解码 | 编解码、转码、流媒体 |
| 实时通信 | WebSocket | 终端状态推送、任务实时更新 |
| 媒体协议 | RTP/RTSP/SIP | 音频流传输、对讲通话 |
